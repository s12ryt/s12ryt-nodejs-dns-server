## 已實作模組

| 路徑 | 責任 | 依賴方向 |
| --- | --- | --- |
| `index.js` | 完整 runtime/native binding 雙 SHA 下載、校驗、快取、載入、SIGTERM graceful close，以及具 DoH CORS 的離線 DNS/DoH 核心。 | 只依賴 Node.js 標準庫；完整 runtime 不反向依賴 bootstrap。 |
| `src/dns/` | DNS wire 編解碼、自訂記錄、CNAME 答案鏈、TTL 快取、解析／診斷政策、DoH 上游及週期健康探測。 | 不依賴 HTTP 管理 UI。 |
| `src/services/` | UDP/TCP DNS、具 endpoint 限定 CORS/preflight 的 DoH，以及具 location、rewrite、headers、多上游、安全限制、磁碟快取、壓縮與 WebSocket 的反向代理。 | 依賴 DNS 核心、route store 與 proxy cache；不依賴管理 UI。 |
| `src/admin/` | 原子設定與 migration、網域工作區、首次設密、session、CSRF、去敏管理／診斷 API、事件及靜態 UI 服務。 | 依賴抽象服務狀態與 Tunnel manager；一般 config API 不得覆寫或洩漏 token。 |
| `src/tunnel/` | cloudflared 下載校驗、跨平台安裝、token 來源 metadata、程序生命週期與 bounded logs。 | token 明文封裝於 manager 私有欄位，經 runtime 協調更新。 |
| `src/storage/` | better-sqlite3 WAL、schema migration／guard、設定歷史、指標、Webhook工作及online backup。 | config仍是可攜來源；SQLite保存正式運行歷史。 |
| `src/observability/` | Prometheus累積／區間指標、敏感JSONL日誌、Webhook HMAC持久重試及統一事件管線。 | 依賴SQLite抽象與memory EventLog，失敗不得阻斷核心服務。 |
| `src/backup/` | 敏感ZIP建立／檢查／匯入／還原／回滾，以及daily／weekly排程與保留策略。 | 依賴SQLite online backup與runtime maintenance callbacks。 |
| `src/web/` | 依網域選取的 DNS master-detail、代理精靈、可觀測趨勢、Webhook、備份還原、全自建 modal、深淺色與鍵盤導覽。 | 只依賴管理 HTTP API；使用內嵌 SVG symbols，不增加前端 runtime 依賴。 |
| `src/runtime.js`、`src/main.js` | 組裝共享狀態、SQLite、observability、備份／維護模式、服務與上游探測啟停、設定熱更新、proxy cache及Tunnel。 | 核心服務不受外部Tunnel、telemetry或排程單點失敗影響；還原時保留admin控制面。 |
| `scripts/build.js`、`scripts/native-bindings.js` | 打包runtime/UI/manifest，下載驗證六組Linux glibc native binding並組裝Release。 | 建置期依賴esbuild與GitHub Release；native tar採路徑、checksum、大小及重複entry防護。 |
| `Dockerfile`、`docker-compose.yml` | Debian、非root、唯讀rootfs、volume、healthcheck與graceful stop容器部署。 | 依賴Node20與`data`持久volume。 |
| `deploy/systemd/` | 專用使用者、tmpfiles/sysusers、service硬化與安裝腳本。 | Linux systemd正式部署；資料寫入`/var/lib/s12-dns-server`。 |
| `tests/unit/` | DNS chain、網域、代理 routes/security/cache、設定 migration 等核心契約與錯誤路徑。 | 與直接實作同一原子變更。 |
| `tests/integration/` | 真實 UDP/TCP/HTTP/WebSocket、DoH CORS/fallback、代理重試／壓縮／cache、管理 API、CNAME 熱更新與 runtime 整合測試。 | 依賴核心及服務模組。 |
| `tests/e2e/` | 首次設密、跨 origin DoH、網域選取與直接歸屬 DNS CRUD、未分組記錄、代理 CRUD、診斷、全自建 modal、Tunnel、主題、鍵盤焦點、reduced-motion 與 375/768/1024/1440 驗收。 | 依賴完整 runtime 與 Playwright。 |
| `.github/workflows/ci.yml` | Node 20/22/24 回歸、E2E、Docker實機health/graceful stop、六組native資產與tag Release。 | Release需test、E2E、deployment全部成功。 |
