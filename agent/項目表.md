## 已實作模組

| 路徑 | 責任 | 依賴方向 |
| --- | --- | --- |
| `index.js` | 完整 runtime 下載、校驗、快取、載入與離線 DNS/DoH 核心。 | 只依賴 Node.js 標準庫；完整 runtime 不反向依賴 bootstrap。 |
| `src/dns/` | DNS wire 編解碼、自訂記錄、TTL 快取、解析政策與 DoH 上游。 | 不依賴 HTTP 管理 UI。 |
| `src/services/` | UDP/TCP DNS、DoH 與 HTTP/WebSocket 反向代理監聽。 | 依賴 DNS 核心與 route store。 |
| `src/admin/` | 原子設定與 migration、首次設密、session、CSRF、去敏管理 API、事件及靜態 UI 服務。 | 依賴抽象服務狀態與 Tunnel manager；一般 config API 不得覆寫或洩漏 token。 |
| `src/tunnel/` | cloudflared 下載校驗、跨平台安裝、token 來源 metadata、程序生命週期與 bounded logs。 | token 明文封裝於 manager 私有欄位，經 runtime 協調更新。 |
| `src/web/` | 桌面/手機管理操作、深淺色與完整互動狀態。 | 只依賴管理 HTTP API。 |
| `src/runtime.js`、`src/main.js` | 組裝共享狀態、服務啟停、設定熱更新，以及 Tunnel token 優先級、重啟與回滾。 | 依賴上述核心模組；核心服務不受 Tunnel 失敗影響。 |
| `scripts/build.js` | 將完整 runtime 與 Web UI 打包成 Release 資產並產生 manifest。 | 建置期依賴 esbuild，不進入執行期。 |
| `tests/unit/` | 各核心契約與錯誤路徑測試。 | 與直接實作同一原子變更。 |
| `tests/integration/` | 真實 UDP/TCP/HTTP/WebSocket 與 runtime 整合測試。 | 依賴核心及服務模組。 |
| `tests/e2e/` | 首次設密、登入、設定、Tunnel、主題與響應式 UI 驗收。 | 依賴完整 runtime 與 Playwright。 |
| `.github/workflows/ci.yml` | Node 20/22/24 回歸、E2E 與 tag Release 發布。 | 依賴 npm scripts 與 build 資產。 |
