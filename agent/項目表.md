## 已實作模組

| 路徑 | 責任 | 依賴方向 |
| --- | --- | --- |
| `index.js` | 完整 runtime 下載、校驗、快取、載入與離線 DNS/DoH 核心。 | 只依賴 Node.js 標準庫；完整 runtime 不反向依賴 bootstrap。 |
| `src/dns/` | DNS wire 編解碼、自訂記錄、CNAME 答案鏈、TTL 快取、解析／診斷政策、DoH 上游及週期健康探測。 | 不依賴 HTTP 管理 UI。 |
| `src/services/` | UDP/TCP DNS、DoH，以及具 location、rewrite、headers、多上游、安全限制、磁碟快取、壓縮與 WebSocket 的反向代理。 | 依賴 DNS 核心、route store 與 proxy cache；不依賴管理 UI。 |
| `src/admin/` | 原子設定與 migration、網域工作區、首次設密、session、CSRF、去敏管理／診斷 API、事件及靜態 UI 服務。 | 依賴抽象服務狀態與 Tunnel manager；一般 config API 不得覆寫或洩漏 token。 |
| `src/tunnel/` | cloudflared 下載校驗、跨平台安裝、token 來源 metadata、程序生命週期與 bounded logs。 | token 明文封裝於 manager 私有欄位，經 runtime 協調更新。 |
| `src/web/` | DNS／網域完整 CRUD、DNS 診斷、代理五步精靈、全自建 modal、服務健康、深淺色、原生微動畫與鍵盤導覽。 | 只依賴管理 HTTP API；使用內嵌 SVG symbols，不增加前端 runtime 依賴。 |
| `src/runtime.js`、`src/main.js` | 組裝共享狀態、服務與上游探測啟停、設定熱更新、proxy cache lifecycle，以及 Tunnel token 優先級、重啟與回滾。 | 依賴上述核心模組；核心服務不受 Tunnel 或 cache 維護失敗影響。 |
| `scripts/build.js` | 將完整 runtime 與 Web UI 打包成 Release 資產並產生 manifest。 | 建置期依賴 esbuild，不進入執行期。 |
| `tests/unit/` | DNS chain、網域、代理 routes/security/cache、設定 migration 等核心契約與錯誤路徑。 | 與直接實作同一原子變更。 |
| `tests/integration/` | 真實 UDP/TCP/HTTP/WebSocket、代理重試／壓縮／cache、管理 API 與 runtime 整合測試。 | 依賴核心及服務模組。 |
| `tests/e2e/` | 首次設密、DNS／網域／代理 CRUD、診斷、全自建 modal、Tunnel、主題、鍵盤焦點、reduced-motion 與 375/768/1024/1440 驗收。 | 依賴完整 runtime 與 Playwright。 |
| `.github/workflows/ci.yml` | Node 20/22/24 回歸、E2E 與 tag Release 發布。 | 依賴 npm scripts 與 build 資產。 |
